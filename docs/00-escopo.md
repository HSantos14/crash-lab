# 00. Escopo

## Objetivo
Aprender engenharia de software completa construindo um sistema de análise e automação
sobre um **jogo crash simulado**: backend, banco, frontend PWA, agente local, licenças,
segurança, integrações e entrega.

## Dentro do escopo
- Motor de análise de velas (frequências, sequências, regras de padrão).
- Jogo crash simulado local com margem da casa configurável.
- Painel web com login restrito, configuração do bot e gestão da banca (banca simulada).
- Agente local instalável que lê o simulador e executa entrada/saída automática.
- Gestão de risco: stop loss, stop gain, limite de perdas seguidas, cooldown, kill switch.
- Licenciamento por token assinado (como exercício técnico).

## Fora do escopo
- Dinheiro real e qualquer integração com plataformas de apostas reais.
- Promessas de lucro ou "previsão" de velas.
- Técnicas para evitar detecção por plataformas.
- Comercialização (pode ser reavaliada no futuro, com consulta jurídica).

## Princípio
O histórico de velas não prevê a próxima rodada. O valor do projeto está no que se aprende
construindo, e o simulador permite provar isso com dados.

## Critérios de sucesso
1. Todas as fases concluídas com testes passando.
2. Um experimento documentado mostrando que regras de padrão não vencem a margem da casa.
3. README e diagramas suficientes para outra pessoa rodar o projeto.
