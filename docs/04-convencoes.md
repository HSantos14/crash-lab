# 04. Convenções

## Git
- Branch principal: `main`. Trabalho em branches `fase-N/descricao`.
- Commits no padrão Conventional Commits: `feat:`, `fix:`, `docs:`, `test:`, `chore:`.

## Python
- Versão 3.11+. Formatação com `ruff format`, lint com `ruff`, tipos com `mypy`.
- Testes com `pytest`. Nomes de arquivo `test_*.py`.

## JavaScript
- Node 20+. ESLint + Prettier. Componentes em PascalCase.

## Documentação
- Todo módulo novo tem README curto. Decisões relevantes viram uma linha em `02-arquitetura.md`.

## Definição de pronto (por fase)
1. Código revisado e commitado.
2. Testes da fase passando.
3. Documentação atualizada.
4. Item marcado no roadmap.
